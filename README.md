# Perspectives

A simple project that gives three views on political topics. 

## Left

I personally lean left, so I will try to write these articles from my own perspective and opinions.

## Right

A friend of mine leans right, so he will give his opinion and perspective in these articles.

## Center

Though difficult to combine perspectives, my friend and I will work on this part together, and hopefully explain why there is a split in opinion.

## Moderation through community

By making this project entirely Open Source, it will show that nothing is censored. After adding a page, nothing will be removed, and any previous entries or edits will be available through the git commit history.
